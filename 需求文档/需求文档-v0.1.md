## 一、项目概述

**项目目标**：为「多面派 · Youniverse」搭建品牌官网，承载品牌叙事与产品介绍，是产品对外的第一载体。

**目标受众**：高势能专业人群——创业者、创作者、专业人士等需要被立体认识的人。

**业务定位**：为高势能专业人群，打造可被识别、可被信任的个人数字名片。

**技术栈**：React + Vite + 纯 CSS（不引入 UI 组件库），单页应用。

**交付物**：本地可运行的前端项目，适配桌面、平板、手机三种尺寸。

**风格参考**：linear.app 的秩序感（细边框、留白、精致排版、克制动效）；品牌寓意解读文档（2026-10-06，Callum）。

## 三、视觉设计规范

### 3.1 基调

暗色宇宙 + Linear 秩序感：深色星空底、星点、渐变光晕为「皮肤」；细边框、留白、精致排版、克制动效为「骨架」。整体气质是精英感、专业感，而非秀场感。

### 3.2 色彩系统（提案，待确认）

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 页面背景 | #0A0A10 | 近黑的深蓝黑，星空底色 |
| 面板/卡片 | #14141C | 比背景微亮一层，用于卡片与浮层 |
| 边框 | rgba(255,255,255,0.08) | 1px 细边框，Linear 式的分层方式 |
| 正文文字 | #E8E8EE | 主内容 |
| 次级文字 | #9C9CA8 | 说明、辅助信息 |
| 弱文字 | #63636F | 标签、注释 |
| 强调色 | #8B7CF6（星云紫） | 按钮、链接、高亮，全站唯一强调色 |
| 渐变光晕 | #8B7CF6 → #4FB8E8 | 紫色到蓝色的渐变，用于星球、光晕、标题点缀 |

强调色备选：星云紫 #8B7CF6（推荐，呼应星云与 linear 的靛紫气质）、靛蓝 #5E6AD2（最接近 Linear 本尊）、青蓝 #4FB8E8（更冷、更「星」）。渐变光晕固定在紫→蓝范围，呼应「宇宙」意象。

### 3.3 字体

- 英文标题与正文：Inter（几何无衬线，Linear 同款气质），仅加载这一个网络字体
- 中文：系统字体栈（苹方 / 微软雅黑 / 思源黑体），不加载中文网络字体。原因：中文字体文件动辄数 MB，会拖慢首屏；各设备系统字体已足够清晰，Linear 的出彩靠的是排版而非特殊字体
- 字号层级：Hero 标题 56–72px；区块标题 32–40px；正文 15–16px；辅助 13px

### 3.4 组件风格

1px 细边框卡片；圆角 8–12px；玻璃质感（半透明底 + 背景模糊）；悬停时边框提亮 + 轻微上浮。

### 3.5 动效（已确认：克制路线）

- 星空：静态随机星点 + 极缓慢漂移，纯 CSS 实现，不引入 canvas 与粒子库
- 滚动渐显：区块进入视口时淡入 + 轻微上移（用浏览器自带的 IntersectionObserver 能力，轻量）
- 悬停微交互：150–200ms 过渡
- 无重型动画、无滚动视差

### 3.6 品牌名层级与 Logo（待确认）

品牌名使用规则，参考泡泡玛特官网（popmart.com.cn）的中英混排手法：

- 核心品牌名：YOUniverse（英文）——用于导航 logo、Hero、区块点缀、页脚等核心位置，视觉上以大写 YOU 作为记忆点
- 中文名「多面派」只出现在小字：导航 logo 旁的小字副标、区块标题旁的小字注、页脚版权行等次要位置
- 界面语言为中英混排：英文承担视觉主体与节奏，中文承担信息说明
- Logo 当前用文字标占位，正式 logo 文件到位后替换，导航与页脚样式预留替换空间

## 五、文案草案

以下为完整文案草案，与既定品牌定位一致，供逐段讨论。

### Hero

- 品牌点缀：标题上方小字「YOUNIVERSE」（呼应核心品牌名与中英混排）
- 大标题：为高势能专业人群打造的个人数字名片
- 副文案：一个网址，立体、动态、长久地呈现完整的你
- 按钮：创建我的宇宙（主）/ 了解更多（次）

### 为什么（痛点）

- 区块标题：自我介绍，不该只有一面
- 三张卡片：
  - 信息是固化的——简历写的是过去，朋友圈只是片段，作品集散落各处
  - 人是流动的——在成长、在跨界、在新领域发光，但自我介绍跟不上
  - 载体是缺失的——缺一个随时能递出去、又能立体呈现自己的节点
- 收束句：缺的不是内容，是一个能把所有面装进去的地方

### 产品

- 区块标题：一张多面名片，一个主宇宙
- 功能点（待产品侧确认）：
  - 多面展示——经历、作品、观点、切面，不限一面
  - 动态更新——名片随人生长，永远是最新的自己
  - 长久留存——一个只属于自己的网址，不随平台算法沉没
  - 一键递出——见面即递，链接即入口
- 配产品界面示意图（占位，后续替换为真实截图）

### 世界观

- 区块标题：社交平台是平行宇宙，个人网站才是主宇宙
- 正文：每个平台只允许以一种身份存在——那是平行宇宙。个人网站是原点：完整、立体、长久。所有平行宇宙，都从这里出发，又回到这里。
- 行星注脚：每个人都是一颗行星；个人网站是持续发出的引力；被引力聚到一起的人，组成星系

### 生态

- 区块标题：不止一个网站，而是一个世界
- 四张卡片（各卡一句话定位，待确认）：

  - 多面派社区——多面派们的归属地
  - 多面派学院——方法论与课程
  - 多面派奖项——对「立体表达自我」的表彰

### 愿景

- 区块标题：人人有宇宙
- 正文：让「拥有个人网站」成为社会的标配——每个人都有自己的宇宙，每一份介绍都值得被完整看见。

## 六、技术实现

- Vite + React，纯 CSS；色彩、间距等设计令牌用 CSS 变量统一管理，方便日后整体换肤
- 组件划分：Nav / Hero / Why / Product / Universe / Ecosystem / Vision / CTA / Footer
- 星空背景：独立背景组件，CSS 星点 + 渐变星云，固定在页面底层
- 滚动渐显：IntersectionObserver（浏览器自带能力，无需第三方库）
- 响应式：桌面优先，平板与手机用断点适配；移动端导航折叠为菜单
- 图片策略：产品示意图等先用 CSS/SVG 绘制占位，正式素材到位后替换
- 依赖克制：除 Inter 字体外不引入重型第三方库，首屏性能优先
